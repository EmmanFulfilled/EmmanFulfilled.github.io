About me

I’m in third year at TU Dublin studying Computing with Machine Learning and Artificial Intelligence, and I’m currently on a 3.73/4.0 GPA (First Class Honours).

Most of my projects so far have been machine learning systems that I’ve taken from data cleaning right through to deployment. I’ve also been getting into backend work: I recently finished a URL shortener in FastAPI with PostgreSQL and Redis, tested with pytest and a GitHub Actions pipeline that runs the linting and tests.

This term I’m working with a teammate on a model that predicts total value locked for DeFi protocols, and I designed and built a cinema booking database in Oracle with PL/SQL transactions.

Outside of my course I’m a Class Rep, Peer Mentor and Student Ambassador at TU Dublin, and in 2026 I received the President’s Volunteering Award. I’ve also worked part-time at Vue Cinemas since 2024, alongside full-time study.

Away from all that, I’m into football, boxing and gaming.

Oct 2026Group of 4

Healthcare Innovation Challenge

Transforming Health 2026 · TU Dublin and Tallaght University Hospital

Our team designed a prototype equipment tracking system for the hospital’s Occupational Therapy department. It replaces a manual Excel process that was causing lost equipment and slow stock checks.

€4,600roughly what the department was losing in equipment every year

What I did

  • Led design and strategy, turning the clinician’s problem into user flows (collect, return, transfer, repair, mark missing) with a PIN-based staff sign-in that suits a busy ward
  • Built the prototype using AI-assisted development
  • Pitched it to a panel from Amazon and Tallaght University Hospital, who praised the interface as clear and easy to use for non-technical clinical staff
  • User flows

Sep – Nov 2026Personal project

URL Shortener

A REST API for short links with custom aliases, plus a small frontend for click analytics.

  • JWT authentication with refresh token rotation, and async click analytics
  • Redis for caching and rate limiting, PostgreSQL for storage, with Alembic migrations
  • Tested with pytest, containerised with Docker Compose, and a GitHub Actions CI pipeline for linting and tests
  • Vanilla JavaScript frontend with Chart.js to visualise the click data
  • Python
  • FastAPI
  • PostgreSQL
  • Redis
  • Docker
  • pytest
  • JavaScript

Oct 2026Individual project, TU Dublin

Cinema Booking Database

A 10-table cinema booking database in Oracle, designed from ER diagrams to third normal form.

  • Constraints that keep the booking data valid, and JOIN queries across the schema
  • PL/SQL transactions that commit a valid booking and roll back when the seat is already taken
  • Oracle SQL
  • PL/SQL
  • ER modelling

Feb – May 2026Group project, TU Dublin

Heart Disease Prediction System

A clinical machine learning system comparing XGBoost, Random Forest and Logistic Regression on a combined dataset of 918 patient records.

  • Handled the full pipeline: data cleaning, preprocessing, training, evaluation and deployment through a Flask web app
  • Random Forest performed best, at 85.3% accuracy
  • Presented the live demo and results to faculty and peers
  • Python
  • scikit-learn
  • XGBoost
  • Flask
